# אתר המשרד - רישטלר עורכי דין

אתר סטטי. הכתובת החיה:
https://ri-law.co.il

מתארח בנטליפיי. כל שמירה (commit) לענף הראשי של המאגר הזה מתפרסמת לאתר אוטומטית תוך כדקה.

## מבנה

- `site/` - קבצי המקור: עמודים (HTML), מאמרים תחת `site/articles/`, עיצוב `site/css/`, סקריפטים `site/js/`, תמונות ופביקונים.
- `tools/build_static.py` - בונה מהמקור את תיקיית `dist/` (קישורים נקיים בלי סיומת, הפניות 301 מהכתובות הישנות, כותרות אבטחה, מפת אתר, מניעת מטמון לקבצי עיצוב וסקריפט).
- `tools/verify_dist.py` - בדיקת איכות על `dist/`: 43 עמודים בשני רוחבי מסך, גלישה אופקית, כותרות, תמונות שבורות, שגיאות קונסול וקישורים פנימיים מתים. דורש Playwright.
- `dist/` - התוצר שנטליפיי מפרסמת. לא עורכים אותו ידנית.
- `netlify.toml` - תיקיית הפרסום היא `dist`, בלי פקודת בנייה.
- `tools/dns-plan.md` - מצב רשומות ה-DNS בלייבדיאנאס.

## עדכון תוכן

1. עורכים את קובץ המקור המתאים תחת `site/`.
2. מריצים `python3 tools/build_static.py`.
3. רצוי: `python3 tools/verify_dist.py` (צריך להסתיים ב-`issues 0`).
4. שומרים (commit) את `site/` וגם את `dist/` ודוחפים לענף הראשי.

## טופס יצירת קשר

הטופס עובד דרך Netlify Forms (שם הטופס: `contact`). כל פנייה נשלחת במייל למשרד ונשמרת בלוח הבקרה של נטליפיי תחת Forms. אם השליחה נכשלת, הגולש מופנה לוואטסאפ.

## הערות

- כותרות האבטחה (CSP ועוד) מוגדרות ב-`dist/_headers` ונוצרות מ-`build_static.py`. שירות חיצוני חדש (למשל אנליטיקס) דורש עדכון שם.
- כתובות ישנות מאתר הוורדפרס (סלאגים בעברית) מופנות ב-`dist/_redirects`.
